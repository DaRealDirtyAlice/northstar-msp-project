# Internal Lab SLA Matrix

These are project targets, not claims about every MSP.

| Priority | Example impact | First response target |
|---|---|---|
| P1 | Company-wide critical service outage | 15 minutes |
| P2 | Multiple users unable to work | 30 minutes |
| P3 | One user materially blocked | 1 hour |
| P4 | General request, information or installation | 4 hours |

Priority is determined from impact and urgency, not from how strongly the user describes the issue.
