# LinkedIn Update Documents

Store one date-prefixed Word document for every publishable milestone or completed Case.

Filename pattern:

`YYYY-MM-DD_CASE-###_short-title_LinkedIn-Update.docx`

For a non-Case milestone, use:

`YYYY-MM-DD_MILESTONE_short-title_LinkedIn-Update.docx`

Every document must include:

1. Publication status
2. Copy-ready LinkedIn post
3. Approved screenshot order and captions
4. GitHub evidence decision
5. Privacy and redaction check
6. Final posting checklist

Use `CASE-UPDATE-TEMPLATE.docx` as the starting point for future Case documents.
